# Agent Skill

Query&View provides a **self-contained core Agent Skill**: a `SKILL.md` that instructs an AI agent how to write and verify Query&View code, including workflow, rules, and verification methods. The content shown on this page is the same material as the core `SKILL.md` in the repository — the documentation site and the README both expand it from that single file, with no separate copy maintained in the docs.

> Viewing the skill content in the documentation site does **not** mean the skill is installed, enabled, or integrated with the SiYuan Agent; the actual status depends on the installation.
