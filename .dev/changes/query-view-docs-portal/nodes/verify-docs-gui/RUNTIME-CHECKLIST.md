# 运行时检查清单 / Runtime Checklist（人工，隔离测试工作区）

**重要：** 本节点（`verify-docs-gui`）**没有**执行以下任何步骤——它们需要真实 SiYuan 实例，只能在隔离的测试工作区（非用户主库）由人工执行。执行前先构建安装：`pnpm run build` 后将 `dist/` 复制为插件目录（或用 `make-install`），在空笔记本的测试工作区中验证。

每项给出：验证内容、操作步骤、通过标准。勾选后请把结果回填到本文件。

---

## A. Help 入口与 Tab 生命周期

- [ ] **A1 帮助菜单只打开文档站**：点击顶栏插件菜单「帮助文档」→ 应打开「Query&View 文档站」Tab，显示首页（侧边栏 10 项分组顺序：首页/快速开始/案例/主题/API 参考/智能体技能）；**不**应在知识库中新建任何笔记。
  - 通过标准：出现文档站 Tab；`blocks` 表中无新增的 `custom-query-view-user-readme` 属性文档；无「创建用户文档」提示。
- [ ] **A2 重复打开**：文档站已打开时再次点击「帮助文档」→ 不产生第二个 Tab（激活既有 Tab 或保持单实例），当前页状态（语言/页面/滚动）不被重置。
- [ ] **A3 关闭与重开**：关闭文档站 Tab 后重开 → 正常重建，无重复事件监听（连续切换页面无报错、无累积滚动行为）。
- [ ] **A4 卸载**：禁用/卸载插件 → 无控制台异常；已打开的文档站 Tab 被清理。

## B. 语言与导航

- [ ] **B1 语言跟随 SiYuan（无站内切换）**：文档站不再提供站内语言切换按钮；文档语言只由初始化时的 SiYuan 界面语言决定——`zh_CN`/`zh_CHT` 界面显示 `docs/zh_CN/` 中文内容，其他界面语言显示 `docs/en_US/` 英文内容；重新打开 Tab 才重新解析语言。
- [ ] **B1a zh_CHT 不回退英文**：SiYuan 界面为繁体中文（`zh_CHT`）时，插件顶栏菜单与文档站侧边栏显示中文文案（`i18n/zh_CHT.json` 生效），文档内容为简体中文（复用中文文档，属本轮已确认行为）；不回退英文。
- [ ] **B3 翻页**：点击各侧边栏条目 → 内容区替换、active 态更新、滚动回顶；快速连续点击不同页面 → 仅最后一次请求的内容生效（无旧页闪回/覆盖）。
- [ ] **B4 404 回退**：临时删掉某语言页面文件（如 `docs/zh_CN/topics/query.md`）→ 显示英文同页 + 提示条「该页面暂无中文版本…」；两语言都删 → 错误视图 + 重试按钮（恢复文件后点重试可加载）。

## C. 渲染与只读

- [ ] **C1 Markdown 渲染保真**：`基本概念` 页的 Query/DataView 关系图以本地 SVG（`docs/assets/query-dataview-overview.svg`）显示，中文/英文页共用同一文件；主 Agent 目视确认布局清楚、无文字重叠；表格、列表、代码块、引用、图片正常；`../../assets/…` 图片以 `http://127.0.0.1:6806/plugins/…/docs/assets/…` 加载（DevTools Network 无任何远程域名请求）。
- [ ] **C2 只读化**：页面内容不可编辑——点击/选中内容不出现编辑光标；`[contenteditable="true"]` 元素（DevTools 检查）全部为 false。
- [ ] **C3 原生编辑器控件已删除（DOM 级，按上下文收窄）**：代码块内只显示文档站自己的「复制」按钮（代码块内无 Lute 原生动作条/复制/菜单图标）；图片旁无 Lute 更多/拖拽/网络来源/标题图标——DevTools 中 `[data-type="NodeCodeBlock"] .protyle-action`、`[data-type="img"] .protyle-action`、`.protyle-action__drag`、`.img__net`、`.protyle-action__title`、`.protyle-attr` 计数为 0（不是 CSS 隐藏，而是 DOM 已移除）；**任务列表复选框（`.protyle-action--task`）必须保留可见**，勾选/未勾选状态与内容不受影响（`.protyle-action` 全局计数不作要求）。
- [ ] **C4 链接**：文档中的 GitHub 等外链可点击并在新窗口打开；`data-href` 为空（危险协议）的链接无指针样式、不可点击。

## D. 复制语义

- [ ] **D1 复制按钮**：每个代码块右上角有「复制」按钮；点击 → 剪贴板内容 = 代码文本（行尾归一化），**不含**「复制」字样；短暂显示「已复制」后复原。
- [ ] **D2 模板复制**：`从模板开始` 页复制出的内容与 `public/example/basic-template.js` 一致（允许一个末尾换行差异、行尾归一化）。
- [ ] **D3 失败回退**：若剪贴板 API 不可用（如特殊权限环境），复制仍通过回退路径成功或给出失败表现（无崩溃）。

## E. API 页动作

- [ ] **E1 工具条**：API 参考页顶部显示「下载」按钮；桌面端另有「在本地打开」按钮（`window.require` 可用时）。
- [ ] **E2 下载**：点击下载 → 得到 `sy-query-view@{version}.types.d.ts`（文件名含当前版本）。
- [ ] **E3 本地打开**：点击「在本地打开」→ 用设置中「打开本地编辑器」命令打开 `data/plugins/sy-query-view/types.d.ts`；命令不可用时无崩溃。
- [ ] **E4 首屏为 API 页**：通过 `docsSite.open("api-reference")`（或等效路径）首次打开直接进入 API 页 → 工具条仍出现（无初始化竞态缺失）。

## F. qv-basic 基础模板

- [ ] **F1 斜杠插入**：文档中键入 `/qv` → 插入「Query View 基本模板」嵌入块，内容与 `public/example/basic-template.js` 一致（不再使用 TS 内嵌第二份模板）。
- [ ] **F2 运行**：插入的嵌入块执行并显示随机 5 个块；断网（离线）环境下仍可插入（模板文件随插件本地打包）。
- [ ] **F3 加载失败表现**：临时删掉 `example/basic-template.js` → 斜杠插入提示「基础模板加载失败」（有提示、无静默失败）。

## G. 旧帮助笔记不受影响

- [ ] **G1 旧笔记保留**：若测试工作区已有一篇带 `custom-query-view-user-readme` 属性的旧帮助笔记 → 本插件版本操作后该笔记内容、属性、位置均不变。
- [ ] **G2 不再更新**：升级插件版本后打开帮助入口 → 旧笔记不被重命名、不更新内容、不创建新副本、无迁移提示。
- [ ] **G3 设置项消失**：插件设置页不再有「用户文档只导入类型参考」；`codeEditor`、表格默认列、echarts 渲染器等其余设置仍在且生效。

## H. 打包与移动端不回归

- [ ] **H1 离线一致**：断网状态下文档站全部页面/图片/案例代码可浏览（内容随插件版本，无远程拉取）。
- [ ] **H2 移动端不回归**：在移动端（或窄窗口）打开含 Query View 块的文档 → 已有 DataView 渲染正常（本变更不要求移动端文档站布局，但不得破坏既有块渲染）。
