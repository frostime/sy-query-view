# Query&View 插件内文档站与智能体技能 — Target SPEC

**状态：** 等待用户反馈
**创建：** 2026-08-11

## Problem Statement

Query&View 当前会把帮助内容创建并维护为用户知识库中的一篇笔记。帮助显示内容因此受版本、设置和更新状态影响，插件也承担了用户日常写 Query View 并不需要的笔记生命周期管理。

用户需要的是一个容易找到、与已安装插件版本一致的帮助入口：第一次或偶尔使用插件时能跑起第一个 Query View；已有明确目标时能找到接近的案例，复制并改造代码。用户不应为了查看帮助而在知识库中产生或更新内容。

## Approach

将帮助入口改为随插件版本发布的**插件内文档站（In-Plugin Documentation Site）**。用户在独立 Tab 中浏览带侧边栏的多篇文档，而不是打开一篇由插件维护的笔记。

人类长篇说明继续以中英文 README 为唯一维护来源，同时供 GitHub、集市和插件内文档站浏览。文档站只组织和呈现这组材料；可运行案例、生成的类型声明和**智能体技能（Agent Skill）**各自保留权威来源。

先完成并验收人类文档和插件内文档站，再编写智能体技能，使技能可以基于已经稳定的说明、案例和类型声明整理规则。第一版核心 `SKILL.md` 保持自包含；后续验证目标 Agent 能否通过文件读取工具访问技能参考材料，再决定是否加入 `references/`。

## Behavior Contract

- 用户点击帮助入口时，插件只打开插件内文档站 Tab；不会创建、修改或删除用户笔记。
- 文档站内容随已安装插件版本发布，离线可浏览；不采用远程动态内容更新。
- 首页按用户任务引导；侧边栏依次组织入门、案例、Query / DataView 主题、API 参考和智能体技能。
- 文档站默认跟随 SiYuan 当前界面语言：中文界面显示中文内容，其他界面显示英文内容。
- 指导和 Examples 位于同一个文档站中。
- 用户可从最小模板开始，也可按需求找到案例；模板和案例均提供明确的复制代码操作。
- 复制代码不会直接向用户笔记插入或修改内容。
- API 参考页提供可读导览，并提供打开或下载完整类型声明的入口；精确签名以类型声明为准。
- 用户可在文档站中查看智能体技能内容；这不表示技能已安装、已启用或已接入 SiYuan Agent。
- 已存在于用户知识库中的旧帮助笔记会被保留，但不再由插件更新，也不会额外显示迁移提示。
- 完整的人类说明仍可在 GitHub 或集市侧浏览。

## Implementation Decisions

### 已确定

- 中英文 README 是人类长篇说明的唯一维护来源；外部页面与插件内文档站不得各自维护独立的长文内容。
- 可运行案例是案例代码的权威来源；精确 API 签名以生成的类型声明为准。
- 核心智能体技能是独立、自包含的材料，但在本变更中安排在人类文档和插件内文档站验收之后编写，以复用稳定材料并减少同步返工。
- 插件内文档站最终显示与核心智能体技能相同的内容，不维护另一份技能说明。
- 文档站内容必须与插件发布版本一致。
- 已有帮助笔记保留原状、停止更新、不额外提示用户。

### 尚未确定

- 文档站各页面的具体内容边界和资料映射。
- 帮助菜单、Examples、类型声明入口、基础模板和旧“只导入类型参考”设置在改版后的保留、替换或移除关系。
- 如何将 README、案例、类型声明和智能体技能组织并呈现为多个页面；页面框架、Markdown 解析和资料拼装方式尚未选择。
- 文档站使用的图片和其他静态材料如何保证离线可用且与发布版本一致。

### 明确延后

- 智能体技能的安装、调用和启用状态展示。
- SiYuan 原生 Agent 或 MCP 的完整集成方式。

## Acceptance Criteria

1. 打开帮助入口不会在用户知识库中产生或更新帮助文档。
2. 用户能在一个与已安装插件版本一致的文档站中完成“从模板开始”或“找到并复制案例”两条路径。
3. 文档站默认按 SiYuan 当前界面语言显示对应的中文或英文内容。
4. API 参考页提供可读导览，并能打开或下载完整类型声明。
5. 外部 README 与插件内文档站来自同一组权威内容，而非两套独立维护的长文档。
6. 每个可复制的模板或案例都能在不修改用户笔记的前提下复制。
7. 旧帮助笔记保留原状、不会再被插件更新，也不会触发额外迁移提示。
8. 用户能在插件内文档站中查看智能体技能内容，但实现不承诺尚未确定的 Agent 集成行为。
9. 核心智能体技能不依赖未经验证的 `references/` 加载机制；若加入技能参考材料，必须先验证目标 Agent 能通过文件读取工具访问其实际安装路径。
