# 演进说明

该变更起于帮助笔记更新后的异常体验：用户看到的思源内帮助笔记只剩 API 类型参考，长篇说明不再出现。调查确认发布包中的 README 是完整的；问题来自插件运行时创建和更新用户帮助笔记所带来的裁剪、版本和设置状态。

用户随后将目标改为插件内文档站：帮助入口打开独立 Tab，用户在带侧边栏的多页面界面中浏览指导、案例、API 参考和智能体技能。文档随插件版本发布，按 SiYuan 当前界面语言显示；中英文 README 仍是外部与内部共用的人类说明来源。用户可复制模板和案例代码，但文档站不直接修改笔记。

既有帮助笔记保留且停止更新，不额外提示用户。实施顺序调整为先完成并验收人类文档和文档站 GUI，再根据稳定材料编写核心智能体技能。核心 Skill 保持自包含；`references/` 是否可用将在 Skill 阶段通过目标 Agent 的文件读取工具实测，不提前假定。

人类文档将迁移到对应的 `docs/zh_CN/` 与 `docs/en_US/` 页面，并由 `docs/TERM.md` 约束中英文译名；README 从 docs 生成、提交并在构建时检查同步。GUI 在现有自定义 Tab 上用原生 TypeScript/DOM 和 SiYuan 样式体系改造。入口收口为一个帮助菜单，移动端文档站体验延期。

文档页面与内容来源规则现已验收：两种语言各有十个对应页面，案例代码仍为独立来源，README 可从 docs 生成，插件内文档站只读取本地打包材料。文档站 GUI、旧帮助退役和用户第一轮反馈修复均已完成；英文自包含核心 Skill 也已按类型声明和运行时别名校正。双语 Skill 页面现在通过占位符从同一个 `SKILL.md` 展开，原始文件随插件打包，自动发布验证已通过。当前代码任务收敛，等待用户在隔离 SiYuan 工作区复测阶段反馈与 Skill 页面；技能参考材料研究和原生 Agent 集成继续延后。主 Agent 保留最终运行时验收与发布判断责任。
